# Social Ace

A simple web prototype to help a shy 7-year-old practise social situations, designed for children who find reading hard.

- **Audio-first:** every screen is read aloud (tap the speaker to hear it again).
- **Stories with Finn the fox:** "Joining a game" (park), "Saying hi back" (school gate), "Saying hello" (new class) and "Is it still funny?" (lunch), with feelings checks, gentle choices, "brave words" to say out loud and a Stop, Look, Think traffic light.
- **Spot the signal:** a quick game of reading another child's face and body language: keep playing, or stop and check?
- **Brave ladder:** five real-life missions to tick off with a grown-up.
- **For grown-ups:** tips on how to use it.

No sign-in, no ads, no chat. Progress is stored only in the browser on that device.

## Run it

It is a single file. Open `index.html` in any browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main`) to get a link that works on a phone or tablet.

## Adding a story

Stories live in the `STORIES` list in `index.html`. Each story is a list of steps: `tell`, `feel`, `choose`, `practise` and `done`.
